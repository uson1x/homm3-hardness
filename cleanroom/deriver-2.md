## 2. Theorem 1 (NP-полнота: один тип, R = 1, один ряд, без препятствий)

Конструкция (увиденная в статье; проверена мной независимо): PARTITION `a_1..a_n`, Σ = 2B. Один ряд
из 5n гексов, `p_j = 5(j−1)`, `E_j` на `5(j−1)+1`; игрок: один тип, dmg 1, hp 5, spd 2, att = def = 1,
запас B; `E_j`: одно существо, hp = value = a_j, spd 1. R = 1, W = B.

*Попытки контрпримера.*
* Досягаемость в одном ряду: соседи гекса — только ±1 по ряду, диагонали уходят в несуществующие ряды.
  Слот j стоит вплотную к `E_j` слева; вправо путь закрыт `E_j`; влево 2 шага до `5j−7`, а правый
  сосед `E_{j−1}` — гекс `5j−8`, на расстоянии 3 > 2. Значит слот j бьёт только `E_j`. Проверено
  скриптом при всех занятых слотах на всех инстансах (n ≤ 4).
* Порядок инициативы/WAIT: игрок (spd 2) быстрее врага (spd 1); неждущий удар ложится до DEFEND.
  Ждущий удар ложится после DEFEND (WAIT-фаза по возрастанию spd) и наносит ≤ c_j. Нужна только
  верхняя оценка — она есть.
* Ретал: урон врага не влияет на цель (kills врагов), R = 1.
* Крайние случаи: n = 1 (a_1 = 2B, слот не может убить — no, PARTITION — no, ✓); Σ нечётна — нужен
  фиксированный no-инстанс (тотальность редукции; в формулировке не оговорено, но тривиально);
  n = 0 — W должно быть > 0, отдаём фиксированный yes-инстанс.
* Гексы `5j−3..5j−1` в блоке пусты: слот j+1 может отойти влево на 2, но там нет смежных врагов ✓.

*Брутфорс* (`t1_partition.py`): все инстансы PARTITION с n ≤ 3, a_i ≤ 6 (43 шт.) и n ≤ 4, a_i ≤ 4
(37 шт.); полный перебор распределений (все векторы с суммой ≤ B) и всех ходов игрока (WAIT, ходы без
атаки, атаки с любого гекса) — ответ игры совпал с PARTITION везде.

*Доказательство.* (⇒) При решении S положить `c_j = a_j` для j ∈ S, остальные слоты пусты, Σ = B ≤
запаса; слот j бьёт `E_j` с места в NORMAL-фазе: Δ = 0, урон = c_j = a_j = hp → kills 1 → value a_j;
итого B = W. (⇐) Пусть игра убивает множество S врагов. Каждый стек бьёт ≤ 1 раза, слот j достигает
только `E_j`, урон ≤ c_j (нижний клэмп max(1,·) не поднимает урон выше c_j при c_j ≥ 1; стек с c_j = 0
не существует); `E_j` гибнет только при накопленном уроне ≥ a_j, т.е. c_j ≥ a_j. Тогда
B ≤ Σ_{S} a_j ≤ Σ_{S} c_j ≤ B, все неравенства — равенства, S — решение PARTITION. Полиномиальность
очевидна; членство — Lemma 2.1. ∎

**Вердикт: доказано** (с оговоркой о тотальности редукции на входах с нечётной суммой). Уверенность
высокая.

## 3. Proposition 1.1 (O(kB)-алгоритм на паросочетательной досягаемости)

*Попытки контрпримера* — здесь я потратил больше всего усилий, т.к. формулировка широкая.
1. **Динамическая досягаемость.** После смерти `E_i` его гекс освобождается, и слот j может дойти до
   врага, которого статически не достигал. Не помогает: при R = 1 каждый стек наносит один удар, враг —
   одно существо, значит каждый убитый враг требует отдельного стека с count ≥ ⌈hp_j/d⌉; общая сумма
   count ≤ B. Любое множество S с Σ_{S} ⌈hp_j/d⌉ ≤ B достижимо и статически. Значит ответ = knapsack
   в обе стороны, независимо от динамики.
2. **Блокировка своими стеками.** Слот i (раньше по индексу) встаёт на докинг-гекс `d_i`, лежащий на
   единственном пути слота j к `E_j`. Тогда j должен либо ждать (и его удар встретит бонус DEFEND —
   при def α бонус max(1,⌊0.2α⌋) даёт f_def < 1 и ⌊c·d·f_def⌋ < c·d для любого c·d ≥ 1, так что
   ровно ⌈hp/d⌉ существ уже не хватает), либо не бить. Это сломало бы DP. **Но такая конфигурация
   несовместима с паросочетанием:** если `d_i` лежит на пути слота j (в пределах его скорости), то
   слот j статически достигает `d_i`, а `d_i` смежен с `E_i`, значит слот j бьёт и `E_i` — два врага у
   одного слота. Формально: пусть в свидетельской игре слоты из S по очереди идут на свои докинги.
   Статический путь P_j (при всех занятых слотах) обходит все p-гексы и всех врагов; если бы он
   проходил через `d_i`, слот j достигал бы `E_i`. Значит P_j свободен в момент хода j. ✓
3. **Чтение «reach» при пустых слотах.** Если досягаемость считать при пустых прочих слотах, путь j
   может идти через `p_i` (занятый в игре). Тогда слот i (стоящий на `p_i`) достигает `d_j` по более
   короткому суффиксу того же пути (скорость одна — один тип) и бьёт `E_j` — противоречие с
   паросочетанием. Обе трактовки дают верный результат.
4. **Скорости врагов** (медленнее/равные/быстрее игрока), **ретал, убивающий существ игрока**,
   **value = 0**, **hp > B·d** — всё включено в рандом-тест, DP не ломается: ретал бьёт после удара,
   удар неждущего стека — до DEFEND в любом случае (одно-раундовая лемма).
5. **Формулировка «O(kB) времени».** B задан в двоичной записи, т.е. это псевдополином — в статье так
   и сказано. Но вход содержит поле n·m и k чисел hp_j длины log; «O(kB)» не покрывает даже чтение
   входа при n·m ≫ kB. Мелкая неточность формулировки: время O(kB) — это время DP после того, как веса
   w_j = ⌈hp_j/d⌉ вычислены и паросочетание известно (оно — гипотеза/обещание, а не вычисляемая часть).
6. **«On the family of Theorem 1 — …»**: неясно, входят ли в гипотезы «один ряд, без препятствий» из
   Теоремы 1 или только перечисленное через тире. По п.1–3 это неважно: результат верен на ЛЮБОМ поле
   с препятствиями при перечисленных гипотезах.

*Брутфорс* (`p11_random.py`): 4 × 20 000 + 1 500 случайных инстансов (поля 1–3 ряда × 3–6 столбцов,
случайные препятствия плотностью 0–0.6, k ≤ 3 слота, случайные att/def/dmg/hp/spd/value обеих сторон
при (★), B ≤ 6), отфильтрованных по статическому паросочетанию при всех занятых слотах; полный перебор
распределений и ходов (включая WAIT и ходы без атаки) против knapsack — **совпадение везде**
(≈ 35 000 нетривиальных, где веса > 1 и ответ > 0).

*Доказательство.* Пусть d — плоский урон типа игрока, w_j = ⌈hp_j/d⌉, v_j — value `E_j`. Утверждение:
оптимум игры = max { Σ_{j∈S} v_j : Σ_{j∈S} w_j ≤ B }.
(≤) Каждый стек делает ≤ 1 удара за раунд (WAIT переносит, не удваивает); враг — одно существо,
гибнет только при накопленном уроне ≥ hp_j; каждый удар ≤ count·d (при (★) удар в NORMAL-фазе равен
count·d, в WAIT-фазе — ≤, т.к. DEFEND лишь понижает f_def; count в момент удара = c (стек до своего
удара не получает урона — враг по (‡) не атакует, ретал — после удара)). Значит убитый `E_j` получил
удары от стеков с суммарным count ≥ w_j; наборы ударивших для разных убитых врагов не пересекаются;
Σ count ≤ B. (≥) По S положить c_j = w_j в слот j (j ∈ S), прочие пусты; в NORMAL-фазе слоты S по
порядку индексов идут по статическим путям (свободны по п.2) на докинги и бьют: урон w_j·d ≥ hp_j,
kills 1. DP 0/1-knapsack: O(kB) времени, O(B) памяти. ∎

**Вердикт: доказано; формулировка нуждается в микроправке** (время O(kB) — для DP при заданной
структуре; гипотеза «паросочетание» должна быть зафиксирована как статическая при всех занятых слотах,
хотя, как показано, обе трактовки эквивалентны). Уверенность высокая.

## 4. Theorem 2 (сильная NP-трудность: запас 1 у каждого типа, 3 ряда)

Конструкция (увиденная; перепроверена): 3-PARTITION `(a_1..a_{3m}; T)`, T/4 < a_i < T/2, Σ = mT.
Поле 3 × (8m+2); `E_g` в `(8(g−1)+1, 1)`, hp T, value 1, spd 1; три деплой-гекса группы g — три из
шести соседей `E_g`; тип `C_i`: dmg a_i, hp 5, spd 2, запас 1; att = def; R = 1, W = m.

*Попытки контрпримера.*
* «Три из шести соседей» — любая тройка? Проверил все 20 троек при m = 1 и все «одинаковые» тройки
  при m = 2: досягаемость слота = {E_g} во всех случаях (расстояние от соседей `E_g` до соседей
  `E_{g±1}` ≥ 5 > 3 = spd+1). ✓ Формулировка корректна для любой тройки.
* Слот может ударить `E_g` только «своим» стеком из 1 существа (запас 1, слот однороден) — урон ровно
  a_i (Δ = 0). Несколько слотов одного типа невозможны (суммарно ≤ 1).
* Ограничение T/4 < a_i < T/2 на самом деле не нужно: сумма ≥ T на группу при Σ = mT и ≤ 3 слотах на
  группу уже даёт равенства и |S_g| = 3 (все a_i > 0, все 3m элементов должны быть использованы).
* Ретал: первый ударивший получает ответ (урон врага ≤ 5 существ не влияет на цель). ✓
* Оставленные дома типы: только уменьшают урон.

*Брутфорс* (`t2_t4_3partition.py t2`): все инстансы с m = 1, T ∈ {7, 9, 11, 13} (все ходы) и m = 2,
T ∈ {7, 9} (ходы без атаки только на докинг-гексы) — все перестановки типов по слотам, полный перебор
игры; ответ совпал с 3-PARTITION.

*Доказательство.* (⇐ 3-partition) группы S_g в слоты g; каждый стек бьёт `E_g` с места, Σ = T = hp,
третий удар убивает; W = m. (⇒) Каждый убитый `E_g` получил ≥ T от стеков своих трёх слотов (только они
его достигают), каждый стек ≤ a_i; S_g попарно не пересекаются; Σ_g Σ_{S_g} a_i ≥ mT = Σ a_i ⇒
равенства, каждый тип использован, |S_g| = 3. Числа полиномиально ограничены (a_i, T унарны в
3-PARTITION; hp 5, spd 2) — сильная трудность. ∎

**Вердикт: доказано.** Уверенность высокая.

## 5. Lemma 3.2 (resource lemma)

*Проверка формулировки.* Для 0 < μ < 1: D(1) = 1; при c ≥ 2: ⌊μc⌋ ≤ μc < c и 1 < c, значит
D(c) < c. Пусть Σ D(c_i) ≥ 3 (суммарный урон ≥ 3 при уроне ≤ D(c_i)). Тогда Σ c_i ≥ Σ D(c_i) ≥ 3.
Если Σ c_i = 3, то все неравенства равенства: D(c_i) = c_i ⇒ c_i = 1 ⇒ r = 3. Обратно, три единицы —
сумма 3. Перебором (скрипт ниже) проверено для μ ∈ {0.3, 0.35, 0.5, 0.9} и всех разбиений c ≤ 12.
Тонкость: лемма верна и при малых μ, где ⌊μc⌋ = 0 (max(1,·) спасает), и при μ близком к 1
(⌊μc⌋ = c − 1 при c(1−μ) ≤ 1 — всё равно < c).

**Вердикт: доказано.** Уверенность высокая.

## 6. Theorem 3 и Corollary 3.1 (один тип, препятствия, сильная трудность)

### 6.1 Почему нужен фактор защиты (мои соображения до построения)

При одном типе игрока и (★) стек из c существ с плоским уроном d наносит c·d. Тогда враг с hp h гибнет
от одного стека размера ⌈h/d⌉, и «убить q врагов запасом 3q» превращается в задачу о паросочетании
слот→враг с ценой ⌈h/d⌉ — полиномиальную. Чтобы заставить ТРИ разных слота кооперироваться, урон
должен быть сублинейным по c, и единственный источник сублинейности в модели — фактор защиты
f_def = 1 − min(Δ⁻/40, 7/10) вместе с нижним клэмпом max(1, ·): при Δ < 0 стек из c существ наносит
D(c) = max(1, ⌊μc⌋), μ = f_def ∈ [0.3, 1). Тогда одиночка наносит 1, а стек из c ≥ 2 — строго меньше c
(Lemma 3.2). Это и делает «hp 3 = три одиночки» дешевле любого другого способа. Выбор μ произволен;
я взял def(Q) = 21 (Δ = −20, μ = 1/2, D(c) = 1,1,1,2,2,3,…), статья — def 27 (μ = 0.35). Обе таблицы
воспроизведены движком.

### 6.2 Конструкция G_3(X, C) (моя)

Вход: X, |X| = 3q, семейство C трёхэлементных подмножеств, инцидентный граф G (вершины X ∪ C, рёбра
e–S при e ∈ S) планарен (PLANAR-X3C; NP-полна по Dyer–Frieze 1986 — цитата из формулировки статьи, не
проверялась мной по первоисточнику).

**Шаг 0 (no-сертификаты).** Если |X| не делится на 3, какой-то элемент не лежит ни в одном множестве,
G непланарен (тест Хопкрофта–Тарьяна), или C = ∅ при X ≠ ∅ — выдать фиксированный no-инстанс
(поле 1×1, один слот, одно существо, врагов нет, W = 1). Если X = ∅ — фиксированный yes-инстанс
(1×2: слот и враг с hp 1, W = 1). Это делает редукцию тотальной.

**Шаг 1 (степени ≤ 3).** Set-вершины имеют степень ровно 3. Element-вершину e степени d ≥ 4 заменяем
на путь e¹–e²–…–e^d, где e^i получает i-е ребро в циклическом порядке вокруг e в планарном вложении;
планарность сохраняется (расщепление вершины вдоль вращения), все степени ≤ 3. Все e^i — «element-
вершины элемента e»; гекс развёртывания p_e получит только e¹.

**Шаг 2 (ортогональное рисование).** Для планарного графа с максимальной степенью ≤ 4 и N вершинами
за полиномиальное время строится планарное ортогональное рисование на сетке O(N)×O(N): вершины — в
целых точках, рёбра — ломаные из горизонтальных/вертикальных отрезков через целые точки, попарно
внутренне непересекающиеся, не проходящие через чужие вершины, в каждую вершину входит ≤ 1 ребро с
каждой из четырёх сторон (Tamassia–Tollis 1989; Valiant 1981; для несвязных графов — компоненты рядом).
Обозначим точку вершины v через (X_v, Y_v).

**Шаг 3 (масштаб).** λ = 12 (чётно), сдвиг 10: точка (X, Y) ↦ гекс (12X + 10, 12Y + 10). Все центры
попадают в ЧЁТНЫЕ ряды, так что локальные шаблоны одинаковы для всех вершин. Гексы двух разных
точек сетки различаются ≥ 12 по одной из координат.

**Шаг 4 (коридоры).** Каждый отрезок рисования между точками A, B (на одной строке или столбце)
превращается в прямую цепочку гексов от гекса A до гекса B (по ряду или по столбцу; в offset-
координатах (x,y) и (x,y+1) всегда смежны, (x,y) и (x+1,y) — тоже). Гексы, лежащие внутри коробки
радиуса 4 вокруг set-вершины (|dx|,|dy| ≤ 4), из коридора удаляются.

**Шаг 5 (set-коробка).** Вокруг гекса z_S (центр) — коробка 9×9. Три ребра S приходят с трёх из
четырёх сторон к «портам» (центр ± (0,4), ± (4,0)). По тому, какая сторона свободна, выбирается один
из четырёх адаптеров (найдены компьютерным поиском, `adapters2.py`, `adapters2.json`): три пути от
портов к трём докингам, образующим ЧЕРЕДУЮЩУЮСЯ тройку соседей z_S — {L, TR, BR} или {TL, R, BL}
(единственные попарно несмежные тройки среди шести соседей, Lemma D.2 — проверяется перебором, т.к.
соседи гекса образуют 6-цикл, в котором несоседние по циклу вершины на расстоянии 2). Свойства
адаптера (проверены скриптом): пути попарно не смежны и не пересекаются (включая два внешних гекса
коридора у каждого порта); ни один гекс пути, кроме докинга, не смежен с z_S; остальные гексы коробки —
препятствия. Докинг, к которому ведёт путь от порта ребра e–S, обозначим d_S^e.

**Шаг 6 (element-коробка).** Вокруг гекса element-вершины — прямые рукава от использованных портов к
центру (всё проходимо, никаких ограничений). Центр e¹ — p_e.

R = 1, W = q. Все числа ≤ poly(N): сильная трудность. Поле O(N)×O(N)·12 гексов.

### 6.3 Инварианты вложения

(I1) Проходимые соседи z_S — ровно три докинга d_S^e (e ∈ S), попарно несмежные; гексы врагов попарно
несмежны. (I2) Компоненты связности проходимых гексов без гексов врагов («регионы») находятся во
взаимно-однозначном соответствии с элементами: R_e содержит p_e и все element-коробки e^i, и множество
врагов, смежных с R_e, есть {z_S : e ∈ S}, причём с каждым таким z_S регион R_e смежен ровно одним
гексом — докингом d_S^e.

*Доказательство.* Два проходимых гекса разных объектов (коридоров разных рёбер, или коридора и коробки
не инцидентной ему вершины, или двух коробок) не смежны: смежность требует |dx| ≤ 1, |dy| ≤ 1; гексы
на разных линиях сетки различаются ≥ 12 по координате линии; гекс вертикального и гекс горизонтального
отрезка смежны, только если оба отрезка содержат общую точку сетки (X, Y) — что для отрезков разных
рёбер или несмежных отрезков одного ребра исключено планарностью; коллинеарные отрезки разных рёбер
разделены ≥ 1 единицей = 12 гексов; коробка радиуса 4 и коридор неинцидентного ребра разделены ≥ 12 − 4
= 8; две коробки — ≥ 3. Внутри set-коробки свойства адаптера дают (I1) и то, что три входящих
коридора не соединяются иначе как через z_S. Значит компонента p_e = рукава element-коробок элемента e
∪ коридоры инцидентных рёбер ∪ пути адаптеров этих рёбер до докингов; она содержит ровно один
p-гекс и смежна ровно с z_S при e ∈ S, единственным гексом d_S^e. ∎

*Проверка скриптом* (`t3_x3c.py`): для случайных инстансов q = 1, 2 (рисование — рандомизированным
поиском на сетке 3×3 / 5×5) инварианты I1, I2 и равенство «статическая досягаемость при всех
занятых слотах = инцидентность» проверены на каждом построенном поле (36×36 … 61×62 гексов).

### 6.4 Корректность

**Lemma A (одно-раундовые верхние оценки).** В раунде 1 каждый стек игрока наносит ≤ 1 удара; урон
стека, развёрнутого с c существами, ≤ D(c) = max(1, ⌊c/2⌋); до своего удара стек не теряет существ
(враг по (‡) не атакует; ретал — после удара). Удар в NORMAL-фазе равен ровно D(c); в WAIT-фазе (после
DEFEND врага: def 25, Δ = −24, f_def = 0.4) — ≤ D(c). Стек может ударить z_S только с гекса, смежного
с z_S, т.е. (I1) с одного из d_S^{e'}, e' ∈ S.

**Lemma B (бюджет).** Пусть игра убивает t врагов. Тогда t ≤ q, и при t = q: каждый слот несёт ровно
одно существо, каждый стек бьёт врага, который гибнет, и каждый мёртвый враг получает удары ровно от
трёх различных одиночных стеков.
*Доказательство.* Мёртвый z_S получил суммарный урон ≥ 3 от ударивших его стеков (одно существо,
kills = 1 ⇔ накопленный урон ≥ 3), каждый ≤ D(c_i); по Lemma 3.2 Σ c_i ≥ 3 по ударившим, с равенством
только для трёх одиночек. Множества ударивших для разных мёртвых врагов не пересекаются (один удар на
стек). Значит 3t ≤ Σ_{мёртвые} Σ_{ударившие} c ≤ Σ_e c_e ≤ 3q, откуда t ≤ q. При t = q все неравенства —
равенства: у каждого мёртвого сумма ударивших ровно 3 ⇒ по Lemma 3.2 ровно три одиночки; всего 3q
одиночек в 3q различных слотах, и Σ_e c_e = 3q ⇒ в каждом слоте ровно одно существо, и каждое из них —
одиночка, ударившая мёртвого. ∎

**Lemma C (confinement).** В ситуации Lemma B (t = q) каждый стек e бьёт врага z_S с S ∋ e, с гекса
d_S^e.
*Доказательство.* Индукция по времени ударов τ_1 < τ_2 < …. Пусть стек e бьёт z_S в момент τ с гекса
h, смежного с z_S; h — докинг d_S^{e'} для некоторого e' ∈ S (I1). Стек e до τ стоял на p_e (WAIT не
двигает) и пришёл на h по пути через входимые в момент τ гексы. Если путь не покидает R_e ∪ {h}, то
h ∈ R_e (h — проходимый не-вражеский гекс, связанный с p_e через такие же гексы), и по (I2) e' = e.
Иначе пусть z' — первый гекс пути вне R_e; по определению региона все проходимые соседи R_e вне R_e —
гексы врагов, значит z' = z_{S'} для некоторого S' и он входим ⇒ z_{S'} мёртв к моменту τ; предыдущий
гекс пути лежит в R_e и смежен с z_{S'}, значит по (I2) e ∈ S'. z_{S'} убит тремя одиночными стеками
до τ; по индукционному предположению каждый из них — элемент S'; они различны ⇒ это в точности три
элемента S', в том числе e. Но стек e бьёт единожды, в момент τ, — противоречие. ∎

**Lemma D (yes ⇒ yes).** Пусть C' ⊆ C — точное покрытие. Развернуть по одному существу в каждый слот
(Σ = 3q = запас). Для e ∈ X пусть S(e) ∈ C' — единственное множество, содержащее e. Игра: в NORMAL-фазе
слоты по порядку индексов; стек e идёт по R_e (все гексы R_e свободны — там нет никого, кроме самого e;
путь ≤ |R_e| < σ шагов) на d_{S(e)}^e и бьёт z_{S(e)} (жив до третьего удара: hp 3, каждый удар
одиночки в NORMAL-фазе = D(1) = 1). Каждое S ∈ C' получает ровно три удара по 1 ⇒ гибнет; убито q
врагов value 1 ⇒ W = q. Ретал (1 урона, Δ = 0) оставляет одиночку живой (hp 2); это ни на что не
влияет. ∎

**Lemma E (yes ⇒ exact cover).** Пусть игра убивает ≥ q врагов. По Lemma B — ровно q, все 3q стеков —
одиночки, каждый бьёт мёртвого врага; по Lemma C стек e бьёт z_S с e ∈ S. Каждый мёртвый z_S получил
удары от трёх различных элементов S, т.е. от всех трёх; каждый элемент ударил ровно один раз. Значит
мёртвые множества попарно не пересекаются и покрывают X — точное покрытие размера q. ∎

Полиномиальность: тест планарности, рисование, масштабирование, адаптеры — poly(N). Теорема 3 доказана;
членство в NP — Lemma 2.1.

**Corollary 3.1.** При заданном распределении «по одному в каждый слот» Lemma D даёт yes при точном
покрытии, а Lemma E (в которой распределение — любое с Σ ≤ 3q, в частности all-ones) — обратное. ∎

### 6.5 Попытки контрпримера и подозрительные места

* **Утечка через мёртвых врагов** — главный риск однотипной конструкции (после смерти z_S его гекс
  соединяет регионы трёх элементов S). Lemma C закрывает её только в «тугом» случае t = q; вне его она
  и не нужна. Целенаправленный тест: q = 2 no-инстансы с попарно пересекающимися множествами (там
  первый убитый враг открывает утечку) — см. §10.
* **Атака с гекса мёртвого врага.** z_S попарно несмежны (расстояние центров ≥ 12), так что стоя на
  мёртвом z_S нельзя ударить другого врага. Проверяется в I1.
* **Не-докинг рядом с z_S.** Исключено адаптером (гексы путей, кроме докинга, не смежны с z_S) —
  проверено скриптом на всех четырёх шаблонах и на всех построенных полях.
* **Два докинга одного z_S смежны** (тогда регионы e, e' слились бы). Исключено выбором чередующейся
  тройки; проверено.
* **Стек из 2 существ**: D(2) = 1 — платит 2 за урон 1; стек из 6: D(6) = 3 убивает в одиночку, но
  стоит 6 = две лишние одиночки. Бюджет 3q ловит это (Lemma B). Проверено перебором ВСЕХ распределений
  с Σ ≤ 3q (при q = 2 — 923 непустых вектора на no-инстансе).
* **WAIT игрока**: удар после DEFEND врага — меньше; переупорядочивание ударов — покрыто индукцией по
  времени в Lemma C (она не использует порядок слотов).
* **Ретал убивает игрока?** Урон Q = 1 при Δ = 0, hp(P) = 2 — нет; впрочем, гибель ударившего ничего
  бы не изменила (объектив — kills врагов).
* **Формулировка**: «all enemy creatures of one type and value 1» ✓; «one creature per enemy stack» ✓;
  «static impassable hexes as the only terrain feature» ✓; «flat damage» ✓ (у обоих типов
  dmg_min = dmg_max = 1); «no abilities» ✓.
* **Подозрительное место формулировки Теоремы 3/Lemma D.4 в статье**: утверждение опирается на
  цитату «Planar X3C NP-полна» [DF86]; я её не проверял. Нужна именно планарность двудольного графа
  инцидентности элемент/множество — статья утверждает, что у [DF86] определение такое.
* **Зависимость от порядка инициативы** отсутствует: все стеки игрока одного типа, порядок по индексу
  слота; враги медленнее (spd 1 < σ), кросс-сторонних ничьих нет.

**Вердикт: доказано (собственная конструкция).** Уверенность высокая по корректности, средняя по
цитатам (планарные ортогональные рисования степени ≤ 4 — классика; Dyer–Frieze — не проверял).

## 7. Theorem 4, Corollary 4.1, 4.2 (без препятствий, полная досягаемость)

### 7.1 Конструкция (моя)

3-PARTITION (a_1..a_{3m}; T), T/4 < a_i < T/2, Σ = mT, числа унарны. Поле 6 рядов × (4m+2) столбцов,
без препятствий. Слоты p_j = (j−1, 0), j = 1..3m (верхний ряд). Враги E_g = (4(g−1)+1, 5), g = 1..m
(нижний ряд, нечётный), одно существо, hp T, value 1, spd 1, att = def = 1, dmg 1. Типы C_i: dmg a_i,
hp 5, spd σ = 6(4m+2), att = def = 1, запас 1. R = 1, W = m.

Соседи E_g = (X, 5): (X−1,5), (X+1,5), (X−1,4), (X,4) — четыре (нижний ряд, нечётный). Соседи разных
E_g не пересекаются и попарно несмежны (расстояние по столбцам ≥ 2 в ряду 5 и ≥ 3 в ряду 4).

**Полная досягаемость.** При всех занятых слотах ряд 0 занят, но ряд 1 свободен; стек с (j−1, 0)
спускается в ряд 1 (сосед (j−1,1) или (j,1) существует при любой чётности) и по свободным рядам
1–3 достигает любого соседа любого E_g; σ ≥ длины любого пути. Проверено скриптом при m = 1, 2.

### 7.2 Корректность

(⇐) 3-partition {S_g}: тип i ∈ S_g назначается врагу g. Стеки действуют по порядку индексов; стек j
идёт к СВОБОДНОМУ соседу E_{g(j)} и бьёт. Реализуемость любого назначения φ (три стека на врага):
в момент хода j заняты только p-гексы ещё не ходивших (ряд 0) и докинги уже ударивших (ряды 4–5);
ряды 1–3 всегда свободны; каждый из четырёх соседей E_g достижим из ряда 3 напрямую, минуя остальные
соседи: (X,4) и (X−1,4) — соседи ряда 3; (X+1,5) — через (X+1,4); (X−1,5) — через (X−2,4); гексы (X+1,4),
(X−2,4) не смежны ни с каким врагом и никогда не заняты. Поскольку у E_g четыре соседа, а ударивших
до j не больше двух, свободный сосед есть. Урон стека = a_i (Δ = 0, count 1, NORMAL-фаза), сумма T =
hp ⇒ E_g гибнет на третьем ударе; m убитых ⇒ W.
(⇒) Каждый убитый E_g получил ≥ T от ударивших его стеков, каждый стек ≤ a_i (count ≤ 1, запас 1) и
бьёт один раз; множества ударивших S_g попарно не пересекаются; Σ_g Σ_{S_g} a_i ≥ mT = Σ a_i ⇒ все
равенства и все типы использованы; T/4 < a_i < T/2 ⇒ |S_g| = 3 (≥ 3 т.к. каждый < T/2; ≤ 3 т.к. каждый
> T/4). 3-partition. Числа ≤ poly ⇒ сильная трудность. ∎

**Corollary 4.1.** При заданном распределении (все 3m типов в слотах 1..3m в любом порядке) (⇐) —
как выше (назначение φ реализуемо при любом порядке слотов), (⇒) — как выше. ∎

**Corollary 4.2.** Объектив — Σ_g (поглощённый урон E_g) = Σ_g min(T, урон по E_g) ≥ mT ⇔ каждый E_g
получил ровно T (суммарный номинальный урон всех стеков ≤ Σ a_i = mT, каждый удар ≤ a_i, бонус DEFEND
строго уменьшает: ⌊a_i(1 − b/40)⌋ ≤ a_i − 1 при b ≥ 1, т.к. a_i(1 − b/40) < a_i, а floor числа, строго

ровно T ⇔ 3-partition (те же аргументы: все типы использованы, тройки). Реализуемость — как в (⇐).
При заданном распределении — то же. ∎

Lemma D/E. Пробелов в формулировках не вижу; единственное, что нельзя оценить без доказательства, — как
статья обосновывает (I1)–(I4) для ВСЕХ выходов алгоритма рисования (у меня это §6.3, аргумент
разделения через «≥ 12 гексов между разными линиями сетки»).

## 9. Общие замечания к формулировкам

1. **Тотальность редукций.** Ни одна формулировка (кроме Lemma D.4) не оговаривает, что делать с
   некорректными входами (нечётная сумма в PARTITION, |X| ∤ 3). Тривиально, но для Karp-редукции
   стоит сказать.
2. **Proposition 1.1, «O(kB)»** — время DP, не всего алгоритма с чтением входа; и «reach» надо
   зафиксировать как статическую при всех занятых слотах (эквивалентность трактовок — §3, п.3).
3. **Theorem 2**: ограничение T/4 < a_i < T/2 не нужно для доказательства (три слота на врага и так
   ограничивают |S_g| ≤ 3); безвредно.
4. **Столбец 0** используется конструкциями Теорем 1, 2 (моя проверка: все 20 троек соседей E_1 при
   X_1 = 1 работают, включая тройки со столбцом 0) и 4 — статья это уже оговаривает (R16).
5. Ни одного контрпримера ни к одному утверждению найти не удалось.
