# Формулировки утверждений статьи (выписка для клин-рум перевывода, deriver-2)

Источник: `homm3/paper/main.md` (только формулировки, доказательства отрезаны) и `homm3/MODEL.md`.

## Модель (ключевые пункты MODEL.md / §2 main.md)

* Гекс-сетка n строк × m столбцов, offset-координаты (чётные ряды сдвинуты вправо): соседи (x,y):
  (x±1,y); при чётном y — (x,y±1),(x+1,y±1); при нечётном y — (x−1,y±1),(x,y±1).
* Непроходимые гексы — статические; гекс живого юнита не входим; мёртвый не блокирует.
* Тип = (att, def, dmg_min, dmg_max, hp, spd, flags), все ∈ ℤ>0, + value ≥ 0. Стек = (тип, c).
* Здоровье (fullUnits, firstHPleft), avail = firstHPleft + hp·fullUnits, count = fullUnits + [firstHPleft>0].
* Урон: Δ = att − def; f_att = 1+min(0.05Δ,4) при Δ>0, иначе 1; f_def = 1−min(0.025(−Δ),0.7) при Δ<0, иначе 1;
  dmg = max(1, ⌊count·d·f_att·f_def⌋), точная рациональная арифметика. d = dmg_min = dmg_max.
* Применение урона: если D < firstHPleft — только firstHPleft −= D; иначе total = max(0, avail−D),
  fullUnits = total div hp, firstHPleft = total mod hp, поправка (0, ≥1) → (hp, −1). Оверкилл теряется.
  kills(D) = 0 при D < firstHPleft, иначе min(1+⌊(D−firstHPleft)/hp⌋, count).
* Раунд: все живые стеки действуют по одному разу в порядке убывания spd; ничьи — сторона (атакующий
  первым), затем индекс слота. WAIT переносит действие в WAIT-фазу, идущую после всех NORMAL, в порядке
  ВОЗРАСТАНИЯ spd (ничьи так же). Ретал-счётчик сбрасывается на границе раунда.
* Движение: BFS по входимым гексам, ≤ spd шагов. WALK_AND_ATTACK: подойти на гекс, смежный с целью, ударить;
  значит melee-стек скорости s бьёт цель на расстоянии ≤ s+1.
* Ретал: удар атакующего первым; защитник отвечает, если жив, атакующий жив, это первый удар действия,
  есть заряд (1 в раунд). Убитый насмерть не отвечает.
* DEFEND: конец хода, +20 % def (целое, минимум +1) до следующего хода стека.
* Политика гарнизона (‡): если стек ещё не ждал в этом раунде — WAIT; при отложенной активации — DEFEND на месте.
* (★): att игрока = def врага = α, Δ = 0, урон стека из c существ с плоским уроном d равен c·d.

## Задача ARMY-ALLOCATION

Вход: поле (n, m, obstacles); k слотов с гексами p_1..p_k; мультимножество A игрока (тип, count);
фиксированная защита — вражеские стеки (тип, count, гекс), играющие (‡); R в унарной записи; W ∈ ℤ>0.
Вопрос: существует ли распределение A по k слотам (в слоте ≤ 1 тип, суммарно по типу ≤ запаса) и
последовательность действий игрока, такие что после R раундов против (‡) суммарная value убитых
вражеских существ ≥ W?
BATTLE-PLAY — то же, но распределение дано на входе.

## Утверждения

* **Lemma 2.1 (membership).** ARMY-ALLOCATION ∈ NP.
* **Theorem 1.** ARMY-ALLOCATION NP-полна уже при R = 1, одном типе существ у игрока, одном существе
  в каждом вражеском стеке, без препятствий, на поле из одного ряда.
* **Proposition 1.1.** На семействе Теоремы 1 — один тип, R = 1, политика (‡), урон по (★), одно существо
  на вражеский стек, и *паросочетательная структура досягаемости* (слот j достигает ровно одного врага
  E_j, каждый враг достигается ровно одним слотом) — ARMY-ALLOCATION решается за O(k·B) времени и O(B)
  памяти, B — запас.
* **Theorem 2.** ARMY-ALLOCATION сильно NP-трудна уже при R = 1, без препятствий, без способностей,
  когда каждый тип имеет запас ровно 1.
* **Theorem 3.** ARMY-ALLOCATION сильно NP-трудна уже при R = 1, одном типе у игрока, одном существе в
  каждом вражеском стеке, всех врагах одного типа и value 1, плоском уроне, без способностей, и
  статических непроходимых гексах как единственной особенности рельефа. С Lemma 2.1 — сильно NP-полна.
* **Corollary 3.1.** Те же инстансы остаются сильно NP-трудными при заданном распределении (по одному
  существу в каждый слот): BATTLE-PLAY сильно NP-трудна на однотипных инстансах.
* **Lemma 3.2 (resource lemma).** Пусть 0 < μ < 1, D(c) = max(1, ⌊μc⌋). Если стеки размеров
  c_1..c_r ≥ 1 наносят одной цели не более D(c_i) каждый и суммарно ≥ 3, то Σ c_i ≥ 3, с равенством
  тогда и только тогда, когда r = 3 и c_1 = c_2 = c_3 = 1.
* **Theorem 4.** ARMY-ALLOCATION сильно NP-трудна уже при R = 1; без препятствий и способностей; каждый
  тип с запасом 1, одно существо на вражеский стек; прямоугольное открытое поле 6 рядов × (4m+2)
  столбцов; и полная досягаемость — в стартовой позиции при всех занятых слотах каждый стек игрока
  может атаковать каждый вражеский стек.
* **Corollary 4.1.** Те же инстансы трудны при заданном распределении. BATTLE-PLAY сильно NP-трудна на
  полях без препятствий с полной досягаемостью.
* **Corollary 4.2 (hit-point objective).** На тех же инстансах заменить цель на суммарно снятые хиты
  (поглощённый урон, оверкилл отбрасывается), порог W_hp = mT. Задача остаётся сильно NP-трудной при
  свободном или заданном распределении.

## Леммы Приложения D (только формулировки; (I1)–(I4) и обозначения d_S^e, z_S, p_e, R_e, G_3 — из
доказательства, которое не читалось)

* **Lemma D.1 (Reach).** При (I1)–(I4) в начале боя стек слота e может ударить ровно врагов E_S с S ∋ e,
  и для каждого такого S его единственный законный гекс подхода — докинг d_S^e.
* **Lemma D.2.** Единственные попарно несмежные 3-подмножества шести соседей гекса — две чередующиеся тройки.
* **Lemma D.3 (Adapters).** Для каждой из четырёх троек входящих направлений есть шаблон 9×9, в котором
  три попарно не касающихся пути ведут от трёх портов к трём докингам, каждый касаясь z_S лишь последним
  гексом; неиспользуемый порт непроходим.
* **Lemma D.4 (Embedding).** По инстансу PLANAR-X3C (N = |X|+|C|) за poly(N) вычисляется либо гекс-поле
  полиномиального размера с препятствиями, гексами врагов z_S и гексами развёртывания p_e, удовлетворяющее
  (I1)–(I4), либо фиксированный no-инстанс G_no (1×1, один слот, одно существо, врагов нет, W = 1) — только
  когда вход некорректен или провален один из poly-time no-сертификатов шага 0.
* **Lemma D.5.** Ни одно существо игрока не гибнет в раунде 1, и каждый стек игрока получает своё действие.
* **Lemma D.6 (Budget).** Пусть игра убивает t врагов. Тогда t ≤ q. Если t = q, то Σ c_e = 3q; в каждом
  слоте ровно одно существо; каждый развёрнутый стек бьёт врага, который гибнет; каждый мёртвый враг
  получил удары ровно от трёх различных одиночных стеков.
* **Lemma D.7 (Confinement).** В ситуации D.6 с t = q, когда стек слота e делает своё завершающее действие,
  все E_S с S ∋ e ещё живы; следовательно (D.1) он может ударить лишь E_S с S ∋ e.
* **Lemma D.8.** Если (X, C) имеет точное покрытие, G_3(X, C) — yes-инстанс.
* **Lemma D.9.** Если G_3(X, C) — yes-инстанс, (X, C) имеет точное покрытие.
